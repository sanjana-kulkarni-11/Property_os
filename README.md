# PropertyOS — Luxury Property Portfolio Operating System

> *"One intelligent command center for your entire property portfolio."*

PropertyOS is an AI-powered private property portfolio management platform designed for high-net-worth individuals, family offices, luxury villa owners, and institutional property investors.

Inspired by private wealth-management dashboards and hyper-luxury engineering (Ferrari SF90 dark stealth aesthetic), PropertyOS provides 3D digital twins of estates, real-time telemetry, automated expense anomaly detection, work-order dispatching, and grounded Gemini AI intelligence.

---

## ⚡ Quick Start

### 1. Installation
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Ensure `GEMINI_API_KEY` is configured for live neural analysis.

### 3. Start Development Server
```bash
npm run dev
```
The application will launch on `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
npm start
```
